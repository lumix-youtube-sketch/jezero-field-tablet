# Хендофф на 3D-фазу

## СТАТУС 3D (остановлено по лимиту, 2026-11-14 ночь)
Готово: `public/index.html` (вся разметка: верхняя панель, левая — часы миссии + карточка образца + легенда,
правая — слои / планировщик / источники данных, таймлайн снизу, интро-брифинг), `public/data/samples.json`
(30 образцов из официальной таблицы NASA, 28 привязаны к позиции ровера по sol), `public/js/route.js` (перенесён).
**Осталось написать:** `public/css/style.css` и `public/js/app.js`. ID элементов — в index.html.

План app.js (three@0.160.0 через importmap, OrbitControls, CSS2DRenderer, Line2):
- fetch `terrain_meta.json`, `waypoints_local.json`, `samples.json`, `elevation.f32`; SCALE=1/20 (1 ед.=20 м), EXAG=3.
- Мэш: свой BufferGeometry 512×252 с билинейной выборкой elev; uv=(u,1-v); материал с `ortho.png` (+ тёплый tint, отключаемый).
- Слои: imagery / elevation (canvas-рампа) / slope (классы <5,5–10,10–15,15–лимит, ≥лимит=красный; пересчёт при смене лимита).
- Путь ровера: Line2, сегменты дробить по ~1 клетке и драпировать по рельефу; пройденное до текущего sol — ярко, остальное — тускло.
- Ровер-маркер (примитивы, ×30, подпись «not to scale») в последней точке с sol ≤ текущего.
- Пины образцов (цвет по типу породы как в легенде), CSS2D-метки с номером; клик → карточка + перелёт камеры + sol.
- Дата: 2021-02-18T20:55Z + sol×88775.244 с (проверено: sol 1215 → 21.07.2024, sol 164 → 06.08.2021).
- Одометрия: бегущий максимум `dist_total_m` (в фиде есть нули).
- Курсор: lat=y/R, lon=x/(R·cos 18.4663°), R=3396190; x=minX+u·width_m, y=maxY−v·height_m.
- Планировщик: клик A/B (отличать от drag) → `findRoute` на полной сетке 1024×503; сравнение «образец→образец»
  с одометрией ровера между их sol (с пояснением, почему путь ровера длиннее: научные остановки, мелкие препятствия).
- Кампании по образцам: #1–9 дно кратера, #10–18 фронт дельты, #19–21 верх веера, #22–24 Margin Unit, #25 Neretva Vallis (Cheyava Falls — NASA: потенциальная биосигнатура, 2025), #26–30 обод.

Не-графическая основа готова и проверена на реальных данных. Ниже — всё, что нужно, чтобы
на следующей модели сесть и делать только 3D-рендер.

## Готовые данные (в `public/data/`, грузятся с сервера)
| Файл | Что | Как использовать в 3D |
|---|---|---|
| `elevation.f32` | **Авторитетные высоты**, Float32 LE, row-major, 1024×503, метры | Мэш-рельеф: `new Float32Array(buf)`, индекс `y*W+x` |
| `terrain_meta.json` | bbox (метры), elev_min/max, grid, m/px | Размеры мира и реальные высоты |
| `ortho.png` | CTX-снимок 2048×1005, выровнен с рельефом | Текстура-drape на мэш |
| `heightmap.png` | 8-бит превью высот (не для точности) | только предпросмотр |
| `waypoints_local.json` | 708 точек маршрута Perseverance, спроецированы (u,v,gx,gy,elev,sol) | Линия реального пути + таймлайн по sol |
| `route_demo.json` | вычисленный безопасный маршрут (path u,v,elev) | Отрисовать красную трассу |

**Геометрия мира (из terrain_meta):** ширина `width_m`, высота `height_m` (метры), сетка `grid.width×grid.height`.
Высота вершины (x,y): `elev_min_m + ...` — бери напрямую из `elevation.f32` (там уже метры).
Координата точки с u,v: `worldX = (u-0.5)*width_m`, `worldZ = (v-0.5)*height_m`, `worldY = elev[y*W+x] * verticalExaggeration`.
Рекомендую вертикальное преувеличение ×2–3 (перепад всего ~1 км на ~18 км — иначе плоско).

## Алгоритм маршрута (готов, `src/route.js`)
```js
import { findRoute } from './route.js';
const r = findRoute(elev, W, H, mppxX, mppxY, {x,y}, {x,y}, { maxSlopeDeg: 25, slopeWeight: 6 });
// r.path (ячейки), r.lengthM, r.maxSlopeDeg, r.avgSlopeDeg
```
Чистый ESM, работает и в браузере. Запрещает склоны круче лимита (непроходимо), штрафует крутизну.
Проверено: sol 13 → sol 2022 = 15.16 км (прямая 12.24, крюк +24%), 243 мс. В 3D дать юзеру кликать
две точки → вызывать `findRoute` → рисовать трассу. Можно добавить слой риска (радиация/тень) в стоимость.

## Проксик (`src/server.js`)
- `/api/img?url=` — тянет снимки NASA с Referer (обход 403), хост-вайтлист (не open-proxy).
- `/api/waypoints` — свежий живой фид «Где Perseverance» (с CORS). Проверено: 200.

## Что строить в 3D (MVP)
1. Террейн-мэш из `elevation.f32` + текстура `ortho.png`, облёт камерой (OrbitControls).
2. Реальный маршрут ровера (голубая линия) из `waypoints_local.json`; маркер позиции по sol + таймлайн.
3. Клик по двум точкам → `findRoute` → красная безопасная трасса + плашка (км, макс. уклон).
4. Переключаемые слои (чекбоксы): снимок / рельеф-раскраска / уклон (считается из elev) / маршрут.
5. Научпоп-оболочка: брифинг миссии + факты из `DATA_DOSSIER.md` §2 с источниками.

## Открытые задачи (для качества/differentiator)
- **POV-снимки:** прямые панорамы MMGIS дают 403 даже с Referer — брать кадры из raw-images
  `mars.nasa.gov/mars2020` через проксик, либо отдельный источник. (не блокер)
- **Слой минералов** (CRISM: оливин/карбонаты) и **термика** (THEMIS) — см. источники в досье §3.
- **Научные точки** (Bright Angel, Masonic Temple, Séítah и т.д.) — проставить реальные координаты.
- **Differentiator:** акцент на текущей фазе (обод кратера, 2026) + «проживаешь реальные решения» + честность данных.
- **HiRISE 0.25 м** (3.2 ГБ) — апгрейд разрешения локального участка, если будет время.
